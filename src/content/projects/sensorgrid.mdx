# SensorGrid

SensorGrid is a production-grade IoT platform where users connect physical devices, receive real-time sensor telemetry, visualize historical data, control devices remotely, configure automated workflows, and monitor entire environments from one calm, data-first dashboard.

## Key Features

- **Sub-Second Telemetry Streaming**: Low-latency WebSocket integration delivering real-time sensor metric updates.
- **Geospatial Mapping & Markers**: Interactive geospatial view capable of rendering 10,000+ live telemetry markers.
- **Automated Alerting & Thresholds**: Configurable threshold triggers for instant status notifications.
- **Historical Telemetry Charts**: Multi-axis time-series visualization built with Recharts.
