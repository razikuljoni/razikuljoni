# InsightDoc

InsightDoc is an AI-driven document intelligence platform built with Next.js, NestJS, PostgreSQL, Prisma, Docker, and vector search capabilities for multi-page PDF analytics.

## Key Features

- **Document Vector Embeddings**: Ingest dense PDF documents and build semantic search indexes.
- **Citation-Grounded Q&A**: Streamed LLM answers with direct page-level citation links.
- **Layout-Aware Extraction**: Precise chunking and table extraction across multi-page technical documents.
- **Containerized Architecture**: Production deployment using NestJS backend and Dockerized PostgreSQL vector store.
