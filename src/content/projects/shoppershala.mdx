# Shoppershala

Shoppershala is a full-featured e-commerce monorepo featuring segregated role portals for buyers, sellers, and system administrators, paired with a custom wallet payment flow and an embedded AI copilot.

## Key Features

- **Multi-Role Workflows**: Independent, secured dashboards tailored for buyers, multi-vendor merchants, and platform admins.
- **Wallet & Transactions**: Internal wallet checkout ledger with instant balance reconciliation and refund states.
- **AI Shopping Assistant**: In-app conversational assistant helping buyers find products according to price point and category.
- **Microservice-Ready Architecture**: Modular Express 5 backend structured with Zod validation schemas and Docker containerization.

## Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express.js 5
- **Database**: MongoDB with Mongoose ORM
- **Validation & DevOps**: Zod, Docker
