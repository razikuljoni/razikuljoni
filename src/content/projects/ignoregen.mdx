# IgnoreGen

IgnoreGen is a fast, AI-powered `.gitignore` file generator designed to eliminate config boilerplate. It supports more than 120+ stacks, frameworks, operating systems, and IDEs with instant multi-selection and intelligent rule synthesis.

## Key Features

- **120+ Presets**: Instant filtering and generation for popular languages, tools, frameworks, and operating systems.
- **AI-Assisted Stacks**: Integrated Google Gemini AI to analyze custom project structures and suggest optimized ignore patterns.
- **Single-Click Export**: Copy to clipboard, download raw `.gitignore`, or generate terminal curl snippets.
- **Fast Modern UI**: Built with Next.js 15, React 19, and Tailwind CSS v4 for instantaneous search and preview.

## Tech Stack

- **Framework**: Next.js 15 (App Router), React 19, TypeScript
- **AI**: Google Gemini AI (`@google/genai` SDK)
- **Styling**: Tailwind CSS v4
