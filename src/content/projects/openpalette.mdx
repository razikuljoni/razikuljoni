# OpenPalette

OpenPalette is a comprehensive VS Code extension suite featuring 11 carefully crafted dark editor themes, over 300+ file icons, 90+ folder icons, and productivity snippets.

## Key Features

- **11 Curated Themes**: High-contrast, balanced dark themes optimized for low eye fatigue during long coding sessions.
- **390+ File & Folder Icons**: Granular, distinct iconography covering modern frameworks, configs, and build systems.
- **Language Snippets**: Rapid boilerplate snippets for TypeScript, React, Next.js, and Node.js.
- **Automated Releases**: Built with standard-version and automated GitHub Actions workflows for streamlined packaging.

## Tech Stack

- **Platform**: VS Code Extension API
- **Language**: TypeScript
- **Automation**: GitHub Actions, Standard Version
