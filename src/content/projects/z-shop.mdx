# Z Shop

Z Shop is a full-stack, scalable e-commerce platform built with Next.js, Node.js, Express, MongoDB, Prisma ORM, and NextAuth.js featuring smart product recommendations, real-time inventory updates, and seamless checkout.

## Key Features

- **Personalized Recommendations**: Smart product discovery driven by search vector queries and user preferences.
- **Real-Time Inventory & Orders**: Instant stock reconciliation and live order status tracking.
- **Secure Authentication & 2FA**: Protected accounts with NextAuth, session management, and optional two-factor authentication.
- **Seller Admin Dashboard**: Comprehensive management interface for product catalogs, analytics, and sales reports.
