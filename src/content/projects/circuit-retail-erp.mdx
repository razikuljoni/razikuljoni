# Circuit-Retail-ERP

Production-ready retail operations suite featuring POS invoicing, inventory management, stock ledger reconciliation, expense tracking, and a live daily sales dashboard built for Dhaka-time retail operations.

## Key Features

- **POS Invoicing**: Rapid multi-item point-of-sale checkout with real-time total and tax calculation.
- **Stock Ledger & Inventory**: Automated stock level tracking, item categorization, and audit log.
- **Expense Management**: Categorized expense tracking integrated into profit/loss reporting.
- **Daily Sales Dashboard**: Real-time sales telemetry, daily performance metrics, and transaction history.

## Tech Stack

- **Framework**: Next.js 16 (App Router), React 19, TypeScript
- **Database & ORM**: Prisma ORM with Turso / libSQL (SQLite)
- **Styling & UI**: Tailwind CSS, Radix UI primitives, Lucide React icons
- **State & Data Fetching**: Zustand, TanStack Query, Recharts for analytics
